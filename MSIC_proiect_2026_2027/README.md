Clasa Menu

Clasa Menu creează un meniu. Meniul are un nume, o poziție și mai multe opțiuni.

Constructori:

Constructor implicit – creează un meniu simplu.
Constructor cu parametri – creează un meniu cu nume și poziție.
Constructor de copiere – copiază un meniu.
Destructor – șterge obiectul. Operatori: Operator Explicație simplă
Schimbă numele meniului.
Adaugă o opțiune. ! Sortează opțiunile A-Z.
Unește două meniuri. / Creează un submeniu cu primele N opțiuni.
Alte funcții:

display() – afișează meniul.
removeMenu() – șterge opțiunile meniului.
getSize() – arată numărul de opțiuni.
Compilare și executare În terminalul Visual Studio Code: g++ -std=c++11 main.cpp -o menu.exe
Pentru executare pe Windows: .\menu.exe

Concluzie (Română A1) Concluzie
Acest proiect este scris în limbajul C++.

Programul creează meniuri și submeniuri.

Utilizatorul poate adăuga opțiuni, schimba numele, sorta și uni meniuri.

Programul folosește clase, obiecte, constructori și operatori.

Acest proiect mă ajută să înțeleg programarea orientată pe obiecte.
